MAGPIE PLUGIN · FREE SEARCH

免费搜索 · 中文介绍

为 Magpie 提供 36 个独立搜索 API：18 个可免密钥来源和 18 个需密钥来源，另有 1 个自动聚合搜索源；直接接入系统联网搜索，无需配置 MCP。11 个研究、视频、天气等扩展工具可按需开启。此版本受 dsh-free-search 启发，并非原版全部功能。

搜索 API · 插件设置

先在「设置 → 模型 → 联网搜索 → 搜索 API」添加「免费多引擎搜索」或任一独立来源；添加并排序后由 Magpie 直接调用。各来源的可选 Key 请填在 Magpie 的搜索 API 项目里，不要填进本页。新增的 18 个来源必须配置密钥、默认关闭，也不会进入聚合池或回退链；需单独添加对应 API。以下启用引擎、回退和语言池设置只控制聚合源；直接添加的独立来源由 Magpie 自己的启停和优先级控制。此面板也显示在「设置 → 插件」中，保存后请在插件列表中关闭再开启插件。

搜索行为

需密钥的独立搜索 API（默认关闭）

以下来源不参与上方聚合设置，必须在 Magpie 搜索 API 中单独添加，并在该 API 的密钥字段填入自己的密钥。它们可能按次计费或只提供有限免费额度，费用与额度以供应商页面为准；不填密钥时调用会直接报错且不会发起网络请求。

11 个可选扩展工具（默认关闭）

原生联网搜索无需这些工具。需要网页正文抓取、带来源研究、视频、天气、引擎诊断或缓存检索时，可单独开启；开启后由 Magpie 的插件工具服务提供，并可在资源库中按 Agent 分配，不会替代上方的原生搜索 API。

搜索结果是不可信外部数据。网页抓取拒绝本地与私有地址。页面本身无法联网；搜索请求经 Magpie 原生搜索流程在插件宿主执行。
